## What changed this session

- Added `lib/health.sh` - pass/warn/fail evaluation layer, reuses IceWarp's
  own System Monitor thresholds instead of hardcoding separate ones where
  possible.
- Added `lib/pdf.sh` - pure-bash PDF writer (no python/wkhtmltopdf dependency
  on the production mail server). Wired into `agent.sh`, controlled by
  `BUILD_PDF` (defaults to on).
- Fixed a stale collector filename reference in `checklist-map.md`
  (`icewarp/storage.sh` -> `icewarp/storage_paths.sh`) and documented 26
  collectors that existed in code but were missing from that doc entirely.
- Synced `VERSION` / `README.md` / `config/agent.conf` version numbers,
  which had drifted (`0.1.1` vs `0.2.0`).
